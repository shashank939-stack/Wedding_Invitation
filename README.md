# ⚜️ शाही विवाह निमंत्रण – शशांक एवं अर्चना ⚜️
### Royal Hindu Wedding Invitation & Cinematic Film Experience

एक भव्य, पारंपरिक, राजसी हिंदू विवाह निमंत्रण डिजिटल प्लेटफॉर्म — विशेष रूप से **श्री शशांक गुर्जर** एवं **सुश्री अर्चना पाण्डेय** के पावन परिणय संस्कार हेतु तैयार किया गया।

---

## 🌟 प्रमुख विशेषताएँ (Key Highlights)

### 🎬 1. सिनेमैटिक विवाह फिल्म (Cinematic Royal Wedding Film)
एक 70-सेकंड की शाही भारतीय विवाह फिल्म अनुभव:
- **सीन 1: मंगलमय शुरुआत — गणेश वंदना**:
  - गहरे मरून रंग के बैकग्राउंड पर स्वर्ण अक्षरों में *“॥ श्री गणेशाय नमः ॥”*
  - भगवान श्री गणेश जी की दिव्य स्वर्णिम कलाकृति, प्रकाश किरणें, और प्रज्वलित दीपक।
  - संस्कृत श्लोक: *“वक्रतुण्ड महाकाय सूर्यकोटि समप्रभ। निर्विघ्नं कुरु मे देव सर्वकार्येषु सर्वदा॥”*
  - पवित्र शंखध्वनि एवं मंदिर की घंटियों की गूँज।
- **सीन 2: दो परिवारों का पावन मिलन**:
  - 3D शाही राजमहल के प्रवेश द्वारों का खुलना।
  - वर: **चिरंजीव शशांक गुर्जर** (पुत्र: श्रीमती ज्ञानेश्वरी जी एवं श्री प्रवीणजी गुर्जर)
  - वधू: **आयुष्मती अर्चना पाण्डेय** (पुत्री: श्रीमती बाबिताजी पाण्डेय एवं श्री कृष्ण कुमार जी पाण्डेय)
  - विवाह तिथि: 10 दिसंबर | स्थल: KRB, Kadola, Harda
- **सीन 3: विवाह की रस्मों का सिनेमैटिक सफर**:
  - 7 दिसंबर — मिट्टी की रस्म (प्रातः 7:30–8:30 बजे)
  - 8 दिसंबर — माता पूजन (सायं 4:00 बजे) एवं गणेश पूजन (सायं 7:00 बजे)
  - 9 दिसंबर — मंडप (प्रातः 7:30 बजे), हल्दी (अपराह्न 3:00 बजे), सगाई (सायं 4:30 बजे), तत्पश्चात महिला संगीत
  - 10 दिसंबर — स्वरुचि भोज (प्रातः 10:00 बजे से), शादी (अपराह्न 1:30–3:00 बजे), बारात (सायं 5:00 बजे), धन्यवाद एवं स्वागत समारोह
- **सीन 4: शाही विवाह का मुख्य दृश्य**:
  - भव्य सुसज्जित स्वर्ण मंडप, पवित्र हवन अग्नि एवं वैदिक मंत्रोच्चार।
  - *“दो परिवारों का पावन मिलन, प्रेम, विश्वास और नए जीवन का शुभारंभ।”*
- **सीन 5: भावपूर्ण समापन एवं मंगल आशीर्वाद**:
  - *“आपकी उपस्थिति हमारे लिए सम्मान, आपका स्नेह हमारी खुशी, और आपका आशीर्वाद हमारा सबसे अनमोल उपहार है।”*
  - विनम्र डिजिटल निमंत्रण संदेश:
    > *“यदि यह निमंत्रण आप तक डिजिटल माध्यम से पहुँचा है और हम व्यक्तिगत रूप से आपके घर आकर निमंत्रण नहीं दे पाए, तो कृपया हमारी इस त्रुटि को क्षमा करें। आप हमारे अपने हैं और आपका स्नेह हमारे लिए अत्यंत मूल्यवान है। कृपया पधारकर नवयुगल को अपना आशीर्वाद प्रदान करें।”*
  - सादर आमंत्रित: **गुर्जर एवं पाण्डेय परिवार** | *“॥ शुभ विवाह ॥”*

### 📖 2. 3D इंटरैक्टिव डिजिटल बुकलेट (Royal 3D Flip Booklet)
- मोबाइल-फर्स्ट एवं टच स्वाइप सपोर्ट (उंगली से स्वाइप करके पन्ने पलटें)।
- रियलिस्टिक 3D पेज कर्ल और पन्ना पलटने की ध्वनि।
- 8 पृष्ठों में पूर्ण विवरण:
  1. **मुखपृष्ठ (Cover)**: शाही मरून वेलवेट एवं स्वर्ण मुहर।
  2. **गणेश वंदना एवं कुलदेवी स्मरण**: पवित्र श्लोक व मंगल भावना।
  3. **वर-वधू एवं परिवार परिचय**: माता-पिता एवं कुल परंपरा का सम्मान।
  4. **कार्यक्रम दिवस १ व २**: 7 एवं 8 दिसंबर की रस्में।
  5. **कार्यक्रम दिवस ३**: 9 दिसंबर (मंडप, हल्दी, सगाई, संगीत)।
  6. **शुभ विवाह दिवस**: 10 दिसंबर का संपूर्ण कार्यक्रम।
  7. **विवाह स्थल एवं दिशा-निर्देश**: KRB, Kadola, Harda (Google Maps लिंक सहित)।
  8. **सादर निवेदक एवं आशीर्वाद**: विनम्र संदेश एवं परिवार का आमंत्रण।

### 🎁 3. डिजिटल सुविधाएँ (Smart Utilities)
1. **व्हाट्सएप पर निमंत्रण साझा करें (WhatsApp Share)**:
   - 1-क्लिक में हिंदी में सुंदर, सुरुचिपूर्ण प्रारूप में तैयार निमंत्रण संदेश प्रियजनों को भेजें।
2. **कैलेंडर में जोड़ें (Add to Calendar)**:
   - 10 दिसंबर के विवाह कार्यक्रम को सीधे Google Calendar या Apple Calendar में `.ics` फाइल द्वारा सेव करें।
3. **गूगल मैप्स नेविगेशन (Google Maps)**:
   - KRB, Kadola, Harda का सीधा नेविगेशन लिंक।
4. **शुभकामनाएँ / आशीर्वाद दीवार (Digital Blessings Wall)**:
   - अतिथि नवदम्पति को अपना मंगल आशीर्वाद लिखकर प्रेषित कर सकते हैं।
5. **वीडियो निर्यात / रिकॉर्ड करें (Download Video)**:
   - HTML5 Canvas व MediaRecorder द्वारा सिनेमैटिक निमंत्रण को वीडियो फाइल (`.webm`) के रूप में डाउनलोड करने की सुविधा।
6. **पुष्पवर्षा नियंत्रण (Petals Shower)**:
   - स्क्रीन पर गुलाब एवं गेंदे की पंखुड़ियों की पुष्पवर्षा को चालू/बंद करने का विकल्प।

## 🌐 सार्वजनिक URL पर Deploy करने के निर्देश (Free Deployment Guide)

यह एक पूर्णतः क्लाइंट-साइड (Pure HTML, CSS, Vanilla JS) ऐप्लिकेशन है, जिसे 2 मिनट में किसी भी फ्री होस्टिंग प्लेटफॉर्म पर लाइव किया जा सकता है:

### विकल्प A: Vercel (अनुशंसित - 1 मिनट में लाइव)
1. टर्मिनल में Vercel CLI चलाएँ:
   ```bash
   npx vercel
   ```
2. निर्देशों का पालन करें (Enter दबाते जाएँ)। आपको तुरंत एक सुरक्षित `https://shashank-archana-wedding.vercel.app` जैसा सार्वजनिक लिंक मिल जाएगा!

### विकल्प B: Netlify (ड्रैग एंड ड्रॉप)
1. [netlify.com](https://app.netlify.com/drop) पर जाएँ।
2. इस पूरे `invitation` फ़ोल्डर को ड्रैग करके ड्रॉप करें।
3. तुरंत फ्री लाइव लिंक प्राप्त हो जाएगा।

### विकल्प C: GitHub Pages
1. इस फोल्डर में Git रिपॉजिटरी बनाएँ:
   ```bash
   git init
   git add .
   git commit -m "Royal Hindu Wedding Invitation for Shashank and Archana"
   ```
2. GitHub पर एक नया रिपॉजिटरी बनाकर पुश करें:
   ```bash
   git remote add origin https://github.com/<your-username>/wedding-invitation.git
   git push -u origin main
   ```
3. GitHub Repository की Settings ➔ Pages में जाकर `Branch: main` सेव करें। आपका निमंत्रण `https://<your-username>.github.io/wedding-invitation/` पर लाइव हो जाएगा!
